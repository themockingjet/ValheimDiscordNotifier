# Icon Brief

## Brand system

- Canvas: 256x256 PNG
- Style: Nordic fantasy, low-poly, hand-painted, Valheim-adjacent
- Composition: centered object in three-quarter perspective
- Frame: retain the existing package icon and its dark-metal treatment
- Lighting: warm upper-left light with cool blue shadow
- Text: none
- Transparency: none

## Mod identity

- Mod name: ValheimDiscordNotifier
- Category: server operations and notifications
- Primary subject: a carved raven messenger carrying a glowing rune
- Supporting objects: a small stone server rune and a subtle radiating signal
- Accent color: Discord blue with muted rune-gold highlights
- Mood: reliable, restrained, and watchful
- Avoid: readable text, copied Valheim UI, webhook URLs, logos, chat bubbles,
  weapons, extra characters, and clutter

## Package requirements

Keep `Thunderstore/icon.png` as an original 256x256 PNG with no secret,
configuration, or readable credential content. Verify its dimensions before
packaging.
